# Dialog Components Documentation

## Overview

This directory contains documentation for dialog components used in Typerefinery CMS dialogs.

## Available Components

### Dialog Fields

- **[Select Component](select.md)**: Atlaskit-powered select/dropdown field with support for inline options, grouped options, and dynamic datasource loading.
- **[Event Actions Component](eventactions.md)**: Atlaskit-powered select field that automatically loads event actions from the component being configured.

### Datasources

- **[Key-Value Datasource](datasource-keyvalue.md)**: Loads select/dropdown options from repository nodes and outputs them as key-value pairs (label-value format).
