# Embed

## Event Actions

- Event Proxy (EVENT_PROXY) -  proxy event to another component or into embeded source.
- Data Request (DATA_REQUEST) - the embeded source is requesting data.
- Data Payload (DATA_PAYLOAD) - send data to embeed source.
- Data Source (DATA_SOURCE) - change source for embeded source.
- Data Refresh (DATA_REFRESH) - notify embeded source to refresh data.
